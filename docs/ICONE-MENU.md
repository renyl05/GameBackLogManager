# Icone menu 2.7

Le icone derivano dalle sei immagini allegate dall’utente. Console, amici, impostazioni, Home ed Esci sono state elaborate con lo strumento integrato ImageGen; per Catalogo è stata mantenuta l’immagine allegata, evitando la variante generata con alone.

Prompt usato: background-extraction; preservare soggetto, colori, proporzioni, prospettiva e stile 3D; eliminare puntini e residui esterni; mantenere intatte le parti bianche, il soggetto completo e margini trasparenti; niente testo o nuovi elementi.

I file sono in resources/menu. MenuIconArt seleziona il soggetto connesso attraverso il canale alpha, conserva i bordi antialias e calcola l’inquadratura; non elimina pixel in base al loro colore. Le immagini sono memorizzate in cache tra le aperture del menu. Statistiche mantiene il disegno nativo già presente.
